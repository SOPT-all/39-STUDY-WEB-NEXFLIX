## 🎯 스터디 목표

1. **무지성 복붙 탈출하기**
2. **앱잼에서 Next.js를 이해한 상태로 사용하기**

---

## 📚 스터디 규칙

### 🗓️ 스터디 진행 방식

매주 발표자가 개념 발표와 실습을 준비하고, 함께 학습합니다.

| ⏰ 기한 | 📝 해야 할 일 |
|---|---|
| 스터디 하루 전 23:59까지 | 주차별 아티클 작성 및 공유, 발표자는 실습 코드 PR 제출 |
| 스터디 시작 전까지 | 지정된 스터디원의 아티클을 읽고 댓글 작성, 실습 코드 리뷰 |
| 스터디 당일 | 발표자의 개념 발표 및 실습 진행 |

### 💻 실습 및 GitHub 규칙

- 1주차를 제외한 모든 주차는 발표자가 실습을 준비합니다.
- PR에 실습 코드를 포함해 스터디원들이 미리 실행해 볼 수 있도록 합니다.

**🌿 Branch Convention**

- 브랜치명: `주차/이름/주제`
- 예시: `week1/chaewon/rendering`

**🔖 Pull Request Convention**

- 제목: `[Week1/이채원] Rendering`
- PR 본문에 학습 내용과 주요 변경 사항을 작성합니다.
- 주제는 커리큘럼에 기재된 이름을 그대로 사용합니다.
- PR은 `main` 브랜치로 생성합니다.
- `main` 브랜치 병합은 스터디 종료 후 일괄적으로 진행합니다.

**📂 Directory Structure**

```text
39-STUDY-WEB-NEXFLIX/
├── .github/
│   └── pull_request_template.md
├── docs/
│   └── name/
│       └── article-name.md
├── practice/
│   └── week1/
│       └── sample/
└── README.md
```

| 경로 | 설명 |
|---|---|
| `docs/` | 스터디원의 아티클을 Markdown 파일로 작성 |
| `practice/` | 발표자가 준비한 실습 코드 (`weekn/` 하위에 작성) |
| `.github/` | PR 템플릿 등 GitHub 설정 파일 |

- 파일명은 **kebab-case**를 사용합니다.
- Next.js 학습은 **Next.js 16 및 공식 문서**를 기준으로 진행합니다.
