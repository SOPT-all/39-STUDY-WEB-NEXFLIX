## 🔨 깨뜨려보기 (확인 후 꼭 되돌리기!)

| ---------------------------------------------------- | ----------------------------- |

| `proxy.ts` 의 `matcher` 에 `"/profiles"` 추가        | 무한 리다이렉트               |
